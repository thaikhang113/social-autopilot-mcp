# Tài liệu dự án Social Autopilot MCP

## Giấy phép và Tính chất
- Dự án Social Autopilot MCP hoàn toàn là mã nguồn mở (open-source), phát hành miễn phí theo giấy phép MIT License.
- Dự án là phần mềm tự do phi thương mại, không có bất kỳ bảng giá hay gói cước thu phí bản quyền nào.

## Tính năng và Kiến trúc
- Đóng vai trò là máy chủ Model Context Protocol (MCP) kết nối các mô hình AI (ChatGPT, Claude) với mạng xã hội.
- Cung cấp tính năng lập lịch đăng bài theo thời gian hoặc biểu thức cron, phân loại bình luận và kiểm chứng tri thức.
- Tự lưu trữ (self-hosted) hoàn toàn trên máy tính cá nhân hoặc server riêng, bảo mật toàn bộ dữ liệu.
